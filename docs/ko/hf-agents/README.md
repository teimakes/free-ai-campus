## 무엇을 배우나요?

LLM이 도구를 선택하고 실행 결과를 다음 행동에 반영하는 흐름을 익힙니다. smolagents·LlamaIndex·LangGraph 예제, Agentic RAG와 평가 과제로 이어집니다.

## 시작 전 준비

Python 함수와 LLM의 입력·출력 개념을 준비하세요. 프레임워크를 모두 익히려 하기보다 하나를 골라 작은 작업을 끝까지 실행해 보는 것을 추천합니다.

## 추천 학습 순서

1. 도구·행동·관찰의 관계와 에이전트 실행 흐름을 정리합니다.
2. 프레임워크 하나로 도구를 연결합니다.
3. 실패 사례를 모은 뒤 Agentic RAG·최종 평가 과제로 넘어갑니다.

확인일 기준 한국어판에는 **2025-05-01 인증 마감**이 남아 있지만 영어판은 마감이 없다고 안내합니다. 인증 절차와 최신 단원은 영어판을 기준으로 확인하세요. 번역 전체를 대조한 것은 아닙니다.

## 직접 해볼 과제

계산 도구 하나를 연결한 에이전트에 정상 질문, 잘못된 인자, 도구 오류를 넣어 보세요. 작업 성공 여부·호출 횟수·오류 처리를 기록합니다. 이 과제는 편집자의 제안이며 실행 검증하지 않았습니다.
