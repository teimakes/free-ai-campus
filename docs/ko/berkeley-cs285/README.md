## 무엇을 배우나요?

행동을 선택하고 보상으로 개선하는 방법을 다룹니다. 모방학습, 정책경사, 가치 기반 학습, 모델 기반·오프라인 강화학습과 2026 자료의 LLM RL 주제로 확장할 수 있습니다.

## 시작 전 준비

공식 선수과목은 CS189 또는 동등한 머신러닝 지식입니다. 기초 강화학습·수치 최적화도 필요합니다. 상태·행동·보상·정책과 MDP를 먼저 설명할 수 있는지 확인하세요.

## 추천 학습 순서

1. 모방학습과 강화학습 기초로 문제 설정을 익힙니다.
2. 정책경사와 가치 기반 학습을 비교합니다.
3. 오프라인 RL 또는 LLM RL 중 목적에 맞는 심화 주제를 고릅니다.

영상과 자료의 차시 번호가 일치한다고 가정하지 말고 **주제명**으로 대조하세요. 특히 2026 LLM RL 자료를 2023 영상이 모두 설명한다고 볼 수 없습니다.

## 직접 해볼 과제

작은 격자 환경에서 무작위 정책과 Q-learning의 보상을 비교하고, 여러 시드에서 결과를 기록해 보세요. 알고리즘보다 먼저 종료 조건과 보상 정의를 점검하는 연습입니다. 편집자의 별도 제안이며 공식 과제 실행 결과는 아닙니다.
