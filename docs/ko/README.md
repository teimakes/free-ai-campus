# 한국어 학습 가이드

[전체 자료 목록](../../README.md)으로 돌아가기

공개 학습 자료를 고르고 시작할 수 있도록 한국어로 작성한 안내입니다. 원문 전체를 번역한 문서가 아니며, 현재 신규 자료 6개를 다룹니다. 각 자료의 원문·기존 한국어판과 함께 읽어 주세요.

## 목적별로 고르기

수준과 학습 순서는 Free AI Campus의 추천입니다. `입문`도 Python 등 표에 적힌 선수지식은 필요합니다.

## 추천 학습 순서

- **모델을 이해하고 싶다면:** 기존 [대학 중심 from scratch 경로](../../README.md#시작하기--start-here)에서 출발합니다. 구현 연습을 늘릴 때 CMU 11-785를, 사전학습 모델 활용으로 넘어갈 때 HF LLM Course를 고릅니다.
- **에이전트를 만들고 싶다면:** Python·LLM 기초 → HF Agents → HF MCP → Microsoft AI Agents의 필요한 설계 패턴 순으로 학습합니다. 서로 겹치는 입문 단원은 건너뛰어도 됩니다.
- **강화학습을 공부하고 싶다면:** 머신러닝·최적화·MDP 기초를 익힌 뒤 Berkeley CS185/285로 넘어갑니다. 에이전트 앱 입문의 필수 선행 과정은 아닙니다.

## 읽는 방법

각 자료 폴더에는 출처·학기·언어·공개 범위, 선수지식, 학습 순서, 작은 실습 목표를 담았습니다. 가이드의 실습은 편집자가 제안한 과제로, 대학의 공식 과제나 실행 검증을 마친 예제가 아닙니다.

자료 열람의 무료 여부와 API·GPU·클라우드 비용을 구분합니다. 번역판에 없는 단원, 인증·마감 안내, 설치 버전은 원문을 함께 확인하세요.
