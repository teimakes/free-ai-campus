# 파일 분석

파일이나 URL 분석을 요청받으면 다음 순서로 처리합니다.

## 1. 본문 읽기

`read_markdown` 도구로 지정된 경로나 URL에서 문서의 내용을 읽습니다.

## 2. 문서 구조 확인

문서의 종류(README, 설명서, 코드, 기사 등), 주요 절과 각 절의 목적, 문서가 다루는 주제를 확인합니다.

## 3. 분석 결과 작성

다음 형식으로 작성합니다.

**문서 종류**  
문서의 유형을 적습니다.

**목적**  
이 문서의 목적을 한 문장으로 설명합니다.

**구성**  

- 첫 번째 절의 제목과 간략한 설명
- 두 번째 절의 제목과 간략한 설명
- 그 밖의 절도 같은 방식으로 작성합니다.

**주요 내용**  

- 문서에서 중요한 내용을 항목별로 적습니다.

**요약**  
문서 전체를 두세 문장으로 요약합니다.

## 작성 기준

중요한 정보를 빠뜨리지 않으면서 간결하게 씁니다. 코드에 관한 문서라면 관련 기술과 의존성을 적습니다. README라면 설치와 사용 방법을 포함합니다.
