## 무엇을 배우나요?

Transformers·Datasets·Tokenizers를 사용해 사전학습 모델을 불러오고 데이터를 준비하며 미세조정하는 흐름을 익힙니다. 영어판은 데이터 품질·LLM 미세조정·추론 모델 단원까지 안내합니다.

## 시작 전 준비

Python과 딥러닝 기초를 준비하세요. PyTorch 경험이 있으면 실습을 따라가기 쉽습니다. 모델을 처음부터 학습하는 경로와 사전학습 모델을 활용하는 이 강좌의 목적을 구분해 선택하세요.

## 추천 학습 순서

1. Transformer 구조와 모델 사용법을 익힙니다.
2. 데이터 처리·토큰화와 미세조정을 연결합니다.
3. 평가 결과를 확인한 뒤 데이터 품질과 심화 단원으로 넘어갑니다.

한국어판의 목차와 후반 단원 소개는 현재 영어판과 차이가 있습니다. 기초 개념은 한국어판을 참고하되, 최신 단원 구성과 예제는 영어판과 대조하세요. 전체 번역 완료로 표시하지 않습니다.
