# Microsoft AI Agents for Beginners — 설계 패턴과 운영

[한국어 가이드 목차](../README.md) · [전체 자료 목록](../../../README.md)

## 자료 정보

- 성격: 한국어 학습 가이드. 원문 번역을 복제한 문서가 아닙니다.
- 제공자: Microsoft.
- 원문: [강좌·코드 저장소](https://github.com/microsoft/ai-agents-for-beginners) · [기존 한국어판](https://github.com/microsoft/ai-agents-for-beginners/blob/main/translations/ko/README.md).
- 언어·버전: 영어·Co-op Translator로 관리되는 자동 한국어 번역 / `main`의 2026-11-10 확인본. 재현용 원문 식별자는 [확인 기록](../../content-update-2026-11-10.md)에 있습니다.
- 공개 범위: 무료 문서·코드와 일부 레슨 영상. 모든 레슨에 영상이 있는 것은 아닙니다. 기본 실습은 Microsoft Agent Framework·Microsoft Foundry Agent Service V2를 사용하며 Azure 계정이 필요합니다. 서비스 사용료는 별도입니다.

## 무엇을 배우나요?

도구 사용, Agentic RAG, 계획, 다중 에이전트, 메모리와 운영 등 문제별 설계 패턴을 살펴봅니다. 확인일의 목록에는 로컬 에이전트와 보안까지 18개 레슨이 있습니다.

## 시작 전 준비

Python·LLM·API 기초를 준비하는 것을 추천합니다. [설치 안내](https://github.com/microsoft/ai-agents-for-beginners/blob/main/00-course-setup/README.md)에서 현재 프레임워크와 서비스 요구사항을 확인하세요. 한국어 문서의 번역 품질·원문 동기화 상태를 전부 검수한 것은 아닙니다.

## 추천 학습 순서

1. 에이전트 개념과 도구 사용을 읽습니다.
2. 만들고 싶은 앱에 맞춰 RAG·계획·메모리 중 하나를 고릅니다.
3. 운영·보안 단원에서 배포 전 점검 항목을 정리합니다.

## 직접 해볼 과제

같은 문서 질문을 단순 검색과 Agentic RAG로 처리하는 실험을 설계해 보세요. 정답률뿐 아니라 호출 횟수·지연·비용을 함께 비교하면 에이전트가 필요한 경우를 판단하는 데 도움이 됩니다. 편집자의 제안이며 코드 실행은 검증하지 않았습니다.
