## 자료 정보

- 성격: 한국어 학습 가이드. 전체 강의 번역이 아닙니다.
- 제공자: Hugging Face, Anthropic 협력 강좌.
- 원문: [MCP Course](https://huggingface.co/learn/mcp-course/unit0/introduction).
- 언어·버전: 영어 / 계속 갱신되는 웹 강좌. 확인일: 2026-11-10. 프로토콜·SDK의 특정 버전 호환성은 검증하지 않았습니다.
- 공개 범위: 무료 문서·실습 안내. 프로젝트를 만드는 데 계정이 필요하며, 연결 서비스·API·호스팅 비용은 별도일 수 있습니다.

## 무엇을 배우나요?

MCP의 구성 요소를 이해하고 외부 도구·데이터를 사용하는 앱을 만드는 과정입니다. 기초 구조에서 시작해 앱 구현과 배포 사례로 이어집니다.

## 시작 전 준비

LLM 기초, API 개념과 소프트웨어 개발 경험이 필요합니다. 예제 언어는 Python 또는 TypeScript입니다. 에이전트의 도구 호출이 낯설다면 [Agents Course 가이드](../hf-agents/README.md)를 먼저 읽어 보세요.

## 추천 학습 순서

1. 호스트·클라이언트·서버의 역할을 그려 봅니다.
2. 도구 하나를 제공하는 서버와 이를 호출하는 앱을 연결합니다.
3. 입력 검증·오류 처리를 확인한 뒤 배포 사례를 따라갑니다.

## 직접 해볼 과제

정해 둔 테스트 메모만 검색하는 읽기 전용 도구를 만들고, 정상 검색과 빈 결과, 잘못된 입력의 응답을 비교해 보세요. MCP 연결과 검색 로직을 각각 점검하는 연습입니다. 편집자의 제안이며 실행 검증하지 않았습니다.

확인 범위: 공식 소개·강의 구성·선수지식·계정 안내. 모든 실습의 실행과 한국어 번역 제공 여부는 검증하지 않았습니다. [확인 기록](../../content-update-2026-11-10.md)
