# 약어 풀이

책과 실습에서 사용하는 약어입니다.

| 약어 | 영어 명칭 | 한국어 뜻 |
|---|---|---|
| A2A | Agent2Agent | 에이전트 간 통신 프로토콜 |
| AST | abstract syntax tree | 추상 구문 트리 |
| CoD | Chain-of-Draft | 간략한 초안을 이어 가는 추론 |
| CoT | Chain-of-Thought | 사고의 연쇄 |
| DPO | Direct Preference Optimization | 직접 선호 최적화 |
| DSA | DeepSeek Sparse Attention | DeepSeek 희소 어텐션 |
| ETO | Exploration-based Trajectory Optimization | 탐색 기반 실행 궤적 최적화 |
| FLOPs | floating point operations per second | 초당 부동소수점 연산 수 |
| GQA | Grouped-Query Attention | 그룹 쿼리 어텐션 |
| GRPO | Group Relative Policy Optimization | 그룹 상대 정책 최적화 |
| IoA | Internet of Agents | 에이전트 인터넷 |
| LLaVA | Large Language and Vision Assistant | 대규모 언어·비전 어시스턴트 |
| LLM | large language model | 대규모 언어 모델 |
| LoRA | Low-Rank Adaptation | 저랭크 적응 |
| LtM prompting | least-to-most prompting | 쉬운 하위 문제부터 차례로 푸는 프롬프팅 |
| MAS | multi-agent system | 다중 에이전트 시스템 |
| MCoT | Multi-modal Chain-of-Thought | 멀티모달 사고의 연쇄 |
| MCP | Model Context Protocol | 모델 컨텍스트 프로토콜 |
| MHA | Multi-head Attention | 멀티헤드 어텐션 |
| MLA | Multi-head Latent Attention | 멀티헤드 잠재 어텐션 |
| MLLM | multi-modal LLM | 멀티모달 대규모 언어 모델 |
| MLP | Multi-Layer Perceptron | 다층 퍼셉트론 |
| MMR | Maximal Marginal Relevance | 최대 한계 관련성 |
| MoE | mixture of experts | 전문가 혼합 모델 |
| MQA | Multi-query Attention | 멀티쿼리 어텐션 |
| ORM | Outcome Reward Model | 결과 보상 모델 |
| PRM | Process Reward Model | 과정 보상 모델 |
| RAG | Retrieval-Augmented Generation | 검색 증강 생성 |
| ReAct | Reason and Act | 추론과 행동 |
| RL | reinforcement learning | 강화 학습 |
| RLHF | Reinforcement Learning from Human Feedback | 사람의 피드백을 이용한 강화 학습 |
| RLVR | Reinforcement Learning with Verifiable Rewards | 검증 가능한 보상을 이용한 강화 학습 |
| RM | reward model | 보상 모델 |
| RoPE | Rotary Position Embedding | 회전 위치 임베딩 |
| SFT | supervised fine-tuning | 지도 미세 조정 |
| TIR | Tool-Integrated Reasoning | 도구 통합 추론 |
| ToM | Theory of Mind | 마음 이론 |
| TTRL | Test-Time Reinforcement Learning | 시험 시점 강화 학습 |
| ViT | Vision-Transformer | 비전 트랜스포머 |
| ViViT | Video Vision Transformer | 비디오 비전 트랜스포머 |
