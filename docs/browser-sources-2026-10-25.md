## 해외 기업·독립 채널

- **Vizuara**: [공개 채널](https://www.youtube.com/@vizuara)은 팀을 AI 스타트업으로 소개합니다. 채널 홈에서 직접 연결한 신경망 직접 구현·ML Teach by Doing 재생목록과 소형 언어 모델 구현 영상을 선별했습니다. 별도 부트캠프나 AI Researcher Bootcamp 전체가 무료라는 주장은 하지 않았습니다.
- **Sebastian Raschka**: [채널](https://www.youtube.com/@SebastianRaschka)의 LLM·추론 모델 직접 구현 영상과 [책 공식 코드 저장소](https://github.com/rasbt/LLMs-from-scratch)를 확인했습니다. 저장소에는 사전학습·미세조정·LoRA·평가 등의 코드 및 [Reasoning from Scratch](https://github.com/rasbt/reasoning-from-scratch) 연결이 있습니다. 대학 정규 강좌로 분류하지 않았으며, 공개 코드와 책·Manning 동영상 강좌를 구분했습니다.
- **Lera Andronova**: [@lerabyte](https://www.youtube.com/@lerabyte)의 자기소개와 실제 ML·LLM 해설 목록을 확인했습니다. [LLM 원리·직접 구현 입문](https://www.youtube.com/watch?v=u1_qczBrhow)을 연결했습니다. 특정 대학 교수·AI 기업 소속이라는 근거가 없어 독립 채널로 표기했습니다. 투자·개인 일상 영상은 선별 대상에서 제외했습니다.
- **Justin Angel**: [Build Your Own LLM Workshop](https://www.youtube.com/playlist?list=PLweJS2YZCfkeXXdfCKGaxAhm2w8p0u1z6)의 게시자는 Justin Angel입니다. 확인일에 26개 항목이 보이며, 일부 `[Refreshed]` 갱신판과 이전 영상이 함께 있습니다. PyTorch, 토크나이저, Attention, 사전학습, 평가, instruction tuning, 강화학습 차시가 있으나 이를 서로 다른 26개 수업으로 단정하지 않았습니다.
- **Syntax**: [LLMs Explained](https://www.youtube.com/watch?v=YmLp8qe87A0)의 실제 게시자는 Syntax입니다. 약 52분 설명 영상과 설명에서 연결한 [예제 저장소](https://github.com/w3cj/how-llms-work)를 확인했습니다. 저장소는 챗봇, 역전파, BPE, Word2Vec, Transformer 학습 데모를 안내합니다. 코드는 실행하지 않았습니다.
- **AI Engineer**: [Training an LLM from Scratch, Locally](https://www.youtube.com/watch?v=UsB70Tf5zcE)는 ElevenLabs의 Angelos Perivolaropoulos가 발표한 약 81분 워크숍이며, 게시자는 AI Engineer입니다. 행사 영상으로 추가했으며 ElevenLabs 공식 정규 교육 과정으로 분류하지 않았습니다.
