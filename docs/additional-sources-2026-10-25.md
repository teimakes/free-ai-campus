# 추가 출처 확인 기록: KOCW·KOOC·이준석·말러랩

확인일: **2026-10-25 (Asia/Seoul)**

사용자가 제시한 네 출처의 실제 홈페이지·카탈로그·채널 재생목록을 확인했습니다. 소개 페이지 확인, 재생목록에 영상이 열거되어 있는지 확인, 영상 전체의 재생·내용 검수는 서로 다른 범위입니다. 이번에는 앞의 두 범위를 수행했으며, 전체 영상 재생·자막·과제 실행은 검수하지 않았습니다.

## 1. KOCW

- 원 출처: [KOCW 홈페이지](https://www.kocw.net/home/index.do)
- 공식 홈페이지에서 대학·교수·분야·강의연도 검색 기능과 최신 강의·공지 목록을 확인했습니다.
- 사이트 검색에서 `딥러닝 생성 모델`을 검색해 김태형 교수의 「딥러닝 생성 모델의 원리와 구현」, 「딥러닝 생성 모델의 이해와 설계」 등이 검색되는 것을 확인했습니다.
- 해당 강좌 상세로 이동할 때 구형 HTTP 강좌 주소로 연결되면서 이 환경에서 본문 확인이 막혔습니다. 차시별 영상 서비스 상태와 강의 학기는 직접 확인을 완료하지 못했습니다.
- **반영:** 국내 공개 강의 탐색 포털로 추가했습니다. 검색 결과만 확인한 개별 강좌를 검증된 공개 영상 강좌로 등재하지 않았습니다.

## 2. KAIST KOOC

- 원 출처: [KOOC 카탈로그](https://online.kaist.ac.kr/kooc)
- 검색 도구로 본문을 읽지 못했지만 브라우저에서 실제 카탈로그를 열어 AI 기초·심화, 데이터사이언스, 수학 등의 분류와 강좌 링크를 확인했습니다.
- 다음 네 강좌의 상세 소개·강사·한국어 표기·상시 운영·신청 버튼·목차를 확인했습니다.

- **반영:** 포털과 상세 강좌 4개를 추가했습니다. 상시 운영을 최신 촬영 연도로 해석하지 않았고, 촬영·개설 학기는 미확인으로 표시했습니다.
- 수강신청은 수행하지 않았습니다. 신청 이후의 학습 화면, 로그인 요건, 전체 영상 재생·수료 과정은 미확인입니다.

- 원 출처: [채널](https://www.youtube.com/@MahlerLab), [재생목록 탭](https://www.youtube.com/@MahlerLab/playlists)

- [LLM 시대의 파이썬](https://www.youtube.com/playlist?list=PL0TnWnPQhDj2XHssyPQvDru4tZipvhmrj)의 설명에 **2024년 1학기 인제대학교 의과대학 의예과 강의용 영상**이라고 명시되어 있음을 확인했습니다. 목록의 파이썬 기초·웹 처리·파일 처리·데이터 분석·챗봇 구현 차시를 확인했습니다.
- 위 파이썬 목록에 표시된 2026년 갱신일을 강의 제작 학기로 쓰지 않았습니다.
- [연구자를 위한 AI Agent 입문 강의](https://www.youtube.com/watch?v=tZ9KFQOA6NM)는 실제 목록에서 제목의 `(2026.4)` 표기와 영상 링크를 확인했습니다.
- **반영:** 연구용 LLM·파이썬 응용 항목으로 재생목록 2개와 개별 강연 1개를 추가했습니다.
- 운영자의 현재 소속·직함은 별도로 확인하지 않았으므로 부여하지 않았습니다. 파이썬 목록의 원 강의 소속 표기는 재생목록 설명에서 확인한 범위에 한합니다.
